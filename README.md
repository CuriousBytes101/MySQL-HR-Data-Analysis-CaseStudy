# HR SQL Case Study

## Overview

A completed SQL case study based on an HR database. The project focuses on exploring and analyzing employee, department, job, salary, manager, and location data using MySQL.

## Project Objectives

- Explore and understand the HR database structure and data.
- Analyze employee information using SQL filtering and functions.
- Perform salary and department-level analysis.
- Apply aggregation using GROUP BY and HAVING.
- Solve business problems using subqueries and nested subqueries.
- Use correlated subqueries for department-level comparisons.
- Apply INNER JOIN, OUTER JOIN, SELF JOIN, and CROSS JOIN.
- Analyze manager–employee relationships.
- Perform advanced salary and employee analysis.
- Strengthen SQL query-writing and problem-solving skills.

## Database Details

The HR database contains information related to:

- Employees
- Departments
- Jobs
- Job History
- Locations
- Countries
- Regions

## Setup

1. Install MySQL and MySQL Workbench.
2. Clone this repository.
3. Open `01_hr-schema-mysql.sql`.
4. Create the database and required tables.
5. Load the HR data.
6. Run the analysis files in sequence.
